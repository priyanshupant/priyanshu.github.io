Part 1 · The video

Act 0 · The hook

The viewer's question: How can a formula possibly count?

Opening 0:00 · act0_opening.py · 8 slides

Familiar ground first: the determinant as a d − b c, and what school taught us it does. It decides whether a linear system has a unique solution (two lines meet, then turn parallel when det = 0), it measures how much a linear transformation scales area (here every area doubles, det = 2), it is zero exactly when the plane is squashed flat (two points land on one), and it even gives the area of any polygon (signed triangles cancel the overhang). Then the turn: one of the most beautiful places it shows up is combinatorics. Title, then “Let's start with a simple puzzle.”

Act 1 · The puzzle

The viewer's question: How many ways can both ants get home without touching?

Hook 0:41 · act0_hook.py · 12 slides

The whole puzzle on one screen. Two ants (“hi!”, “yo!”) in a grid-like world want to get home. Rules, as bullets on the right: step up or right; paths never touch, because they had a fight, and not even later, because ants leave a scent trail (so we count vertex-disjoint paths). Many paths home, some crossing. How many pairs of paths get them home without intersecting? One is easy to find; one crosses. Then all 36 pairs are checked, the first few slowly, then fast: 20 never meet, 16 meet.

TableAndDet 1:52 · act3_two_walkers.py · 7 slides

Same grid; only the right-hand side changes. “Here comes an old friend”: a 2×2 matrix A whose rows are the ants and columns the houses. Each entry is counted path by path: 6 from the blue ant to its home, 4 to the orange house, and by symmetry 4 and 6. Then det A = 6·6 − 4·4 = 36 − 16 = 20, the same number. Coincidence? Hardly.

Act 6 · Disguises

The viewer's question: What else is secretly non-touching paths?

ArcticCircle 12:00 · act6c_arctic.py · 4 slides

A uniformly random tiling of a big diamond (order 60, via domino shuffling): frozen brick-wall corners, chaos inside, and a perfect circle between them (Jockusch–Propp–Shor 1995). That's the picture from the very start.

Act 7 · When it breaks

The viewer's question: Does the plain determinant always work?

SmallBoard2 12:31 · act8_dominoes.py · 4 slides

Dominoes on a chessboard are perfect matchings, not paths. The 0/1 adjacency determinant of a 2×3 board is −1, not 3: the signs cancel good configurations.

SignFix2 13:07 · act8_dominoes.py · 3 slides

Kasteleyn (1961): if the signs don't cancel the way you want, change the signs. Flipping one edge makes all three tilings carry the same sign: det = −3, so 3.

Board4x4 13:33 · act8_dominoes.py · 2 slides

On 4×4 the plain determinant says 0 (“very confident, very wrong”); with minus signs on every other column, |det| = 36, which is right.

FKT 13:50 · act8_dominoes.py · 5 slides

On the full chessboard: 12,988,816, the five-month count, instantly. The rule is that every 4-cycle carries an odd number of minus signs. It works for any planar graph: the FKT algorithm counts perfect matchings in polynomial time.

Act 8 · Why it matters

The viewer's question: So what?

Map 14:41 · act9_ending.py · 2 slides

Ants, hexagons, boxes, mountains, diamonds, chessboards: all counted by one determinant each.

Finale 14:56 · act9_ending.py · 5 slides

The same move every time: count everything with signs and let the bad cases cancel in pairs. For computer science this is remarkable. Counting perfect matchings in general is #P-complete (Valiant 1979), but non-touching paths and planar matchings reduce to a single determinant, computable in polynomial time.

Goodbye 15:40 · act9_ending.py · 2 slides

The ants walk home: twenty ways, and they never had to meet.

Part 2 · Making it with manim-slides

The idea in one paragraph

Every act is a Manim scene class (in act*.py) that inherits from DScene in common.py. Inside a scene, self.cue(k) marks where narration line k begins. The same code renders two ways:

  • Slides mode (SLIDES=1): DScene becomes a manim-slides Slide, and every cue(k) becomes self.next_slide(notes=line k). So you get one slide per line, with that line as the speaker note. Use this to build, edit and present.
  • Video mode (default): cue(k) waits until line k starts in the recorded voice, so the picture stays in sync with the audio. Use this for the final film.

A scene, as you'll edit it

class OneGoodPair(DScene):
    def construct(self):
        lat = Lattice(4, spacing=1.2, center=GRID_C)
        L, N = ant(ANT1).move_to(lat.p(*A1)), ant(ANT2).move_to(lat.p(*A2))
        self.add(lat, endpoints(lat), L, N)

        self.cue(0)                      # slide 0: "Here's one. Ant one goes up first…"
        for step in walk_steps(lat, [(L, GOOD_P, ANT1), (N, GOOD_Q, ANT2)])[0]:
            self.play(step)

        self.cue(1)                      # slide 1: "They never meet. Peace in our time."
        msg = T("They never meet.", 34).to_edge(RIGHT)
        self.play(FadeIn(msg))

The words for each cue live in narration.json under the scene name, in the same order. A number in that list is a pause in seconds.

Setup (once)

pip install manim==0.22.1 manim-slides           # + ffmpeg on your PATH
pip install "manim-slides[pyside6]"              # only for the presenter window
pip install kokoro-onnx soundfile numpy          # only to re-record the AI voice

manim-slides 5.7 expects three config keys that Manim 0.22 removed. common.py adds a small compatibility shim, so nothing needs downgrading.

The editing loop, slide by slide

# 1. render one act as slides (one slide per narration line)
SLIDES=1 manim -qm act3_two_walkers.py TableAndDet        # Windows: $env:SLIDES='1'; manim -qm ...

# 2. present it: → / ← / space; notes = what you say
manim-slides present TableAndDet
#    …or as a browser deck (press S for speaker notes)
manim-slides convert TableAndDet slides/TableAndDet.html

# 3. edit the code or narration.json, repeat 1–2

# all acts as one deck: slides/presentation.html
bash render_slides.sh m

To add a slide, add a line to narration.json and a matching self.cue(k) before the animation that goes with it. To split a slide, split the line in two and add a cue. The cue count must equal the number of spoken lines (pauses don't count).

From slides to the final video

  1. Voice. python audio/tts.py --scene TableAndDet re-records one act with the placeholder AI voice and writes line timings to audio/voice/timing.json. To use your own voice, record audio/voice/<Scene>.wav per act, reading the captions above, and put each line's start and end seconds in timing.json.
  2. Render in video mode. manim -qm act3_two_walkers.py TableAndDet (no SLIDES). The cues now wait for your voice. Lags are logged in logs/cue_lags.json.
  3. Mix. python audio/mix.py 720p30 joins all acts and adds voice, sound effects, a quiet music bed, and captions. It produces final_720p30.mp4 (soft subtitles), final_720p30_captioned.mp4 (burned-in) and captions.srt. python assemble.py 720p30 --chapters-only writes chapters.txt.

The Studio (python studio.py, then open http://localhost:8765) does steps 1–3 for one act with a button, and plays the voiced video slide by slide. VS Code tasks (Terminal → Run Task) cover the same commands.
